# internet-speed-test

Консольный скрипт на Python для замера скорости скачивания.

Скрипт делает 10 запросов к указанному адресу **последовательно**, на каждом дочитывает ответ до последнего байта, а затем печатает:

- время и скорость каждого запроса;
- среднее время запроса;
- общий объём скачанных данных;
- итоговую скорость скачивания.

Внешних зависимостей нет, только стандартная библиотека Python.

## Требования

- Python 3.8 или новее (проверено на Python 3.13, macOS).
- Ставить пакеты не нужно, `pip install` не требуется.

## Запуск

```bash
git clone https://github.com/Shubayevn/internet-speed-test.git
cd internet-speed-test
python3 netspeed.py <URL>
```

На Windows вместо `python3` используйте `python` или `py`.

Примеры:

```bash
# файл на 25 МБ с CDN Cloudflare
python3 netspeed.py "https://speed.cloudflare.com/__down?bytes=25000000"

# тяжёлая картинка (JPEG 5000×3333, ~1.8 МБ)
python3 netspeed.py "https://picsum.photos/id/1015/5000/3333.jpg"
```

Адрес лучше брать в кавычки, иначе shell может обработать символы `?` и `&`.

### Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `url` | — | адрес, к которому делаются запросы (`http://` или `https://`) |
| `-n`, `--count` | `10` | сколько запросов сделать |
| `-t`, `--timeout` | `30` | таймаут в секундах на подключение и на ожидание очередной порции данных |
| `-h`, `--help` | | справка |

## Единицы измерения

| Величина | Единица |
|---|---|
| Время запроса | секунды, **с** |
| Объём данных | мегабайты, **МБ** (1 МБ = 1 000 000 байт), рядом точное число байт |
| Скорость скачивания | мегабиты в секунду, **Мбит/с** (1 Мбит = 1 000 000 бит) |

Мбит/с выбраны потому, что в них указывают скорость тарифов провайдеры и сервисы вроде Speedtest, так что результат можно сразу сравнить с тарифом. Чтобы перевести в МБ/с, разделите на 8.

## Как считается

- **Время запроса** отсчитывается от отправки запроса до получения последнего байта тела ответа. В него входят DNS, установка TCP/TLS-соединения, ожидание ответа сервера и само скачивание, то есть всё время, которое пользователь ждёт файл.
- **Среднее время** = сумма времени всех запросов / число запросов.
- **Общий объём** = сумма размеров тел всех ответов (заголовки HTTP не считаются).
- **Скорость скачивания** = общий объём × 8 / суммарное время запросов / 1 000 000 → Мбит/с.
- Запросы идут строго по очереди: следующий отправляется только после того, как предыдущий ответ дочитан до конца.
- Скрипт отправляет `Accept-Encoding: identity` и `Cache-Control: no-cache`, чтобы сервер отдавал файл без сжатия и мимо кэшей. Иначе объём и скорость были бы искажены.
- Если ответ оборвался раньше, чем обещал `Content-Length`, сервер вернул ошибку (4xx/5xx) или не удалось подключиться, скрипт пишет номер запроса и причину и завершается с кодом `1`. Неверные аргументы дают код `2`.

Результат зависит не только от канала, но и от сервера. Если сервер генерирует файл на лету или ограничивает скорость отдачи, замер покажет меньше, чем позволяет канал. Для замера самого канала берите большой файл (десятки мегабайт) на быстром CDN, например адрес Cloudflare из примеров выше.

## Тесты

```bash
python3 -m unittest -v
```

Тесты поднимают локальный HTTP-сервер, поэтому интернет для них не нужен. Они проверяют:

- что делается ровно N запросов и каждый скачивается целиком;
- что объём и скорость считаются правильно;
- что отправляются заголовки без сжатия и без кэша;
- что HTTP-ошибка и оборванный ответ дают понятную ошибку с номером запроса;
- что неверные аргументы отклоняются.

## Структура

```
netspeed.py              # скрипт
tests/test_netspeed.py   # тесты
```
